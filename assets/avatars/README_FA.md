# دارایی‌های تصویری نسخه ۱۰.۲

این پوشه باید شامل ۳۶ فایل WebP باشد:
- `gulf-01.webp` تا `gulf-18.webp` — آواتارهای خلیجی پولی
- `fantasy-01.webp` تا `fantasy-18.webp` — آواتارهای فانتزی رایگان

فایل‌های بهینه‌شده در بستهٔ جداگانهٔ `DoubleKout-10.2-Avatar-Assets.zip` تحویل شده‌اند.
پس از استخراج، تمام فایل‌ها را در همین مسیر `assets/avatars/` مخزن قرار دهید.
ابعاد هر تصویر ۱۶۰×۱۶۰ پیکسل است؛ فرمت WebP با شفافیت و حجم مجموع حدود ۲۲۶ کیلوبایت.

قیمت پیش‌فرض هر آواتار خلیجی در Migration نسخه ۱۰.۲ برابر ۸۰ امتیاز است؛ قیمت در جدول `store_avatars` قابل تنظیم است.
آواتارهای فانتزی رایگان هستند.
